# Lidd School CRM — план разработки

Каждый этап заканчивается работающей версией, зелёными тестами и коммитом.
Перед началом этапа — план в режиме планирования, согласование, потом код.

## Этап 1. Фундамент
- Проект Next.js + TS + Tailwind + shadcn/ui, Prisma + PostgreSQL (локально через Docker Compose).
- Миграции по `prisma/schema.prisma`, сид-данные (см. ниже).
- Вход по email/паролю, роли OWNER / ADMIN / TEACHER, защита маршрутов и серверных действий по роли.
- Каркас интерфейса: левое меню (8 пунктов в порядке из CLAUDE.md), верхняя панель, меню профиля, токены цветов.
- Доменный модуль `src/domain` с тестами:
  - `pricing` — часы урока, цена урока по программе и способу оплаты, тариф на дату;
  - `schedule` — уроки серии в заданном месяце (с учётом startsOn/endsOn, пояса школы);
  - `monthlyInvoice` — расчёт счёта: уроки, часы, сумма, поурочная сумма, выгода, долг, итог, текст сообщения;
  - `payroll` — начисление за урок и зарплата месяца с надбавками (оба режима bonusApply).
- **Готово, когда:** все контрольные примеры из CLAUDE.md проходят; можно войти тремя ролями и увидеть разный набор пунктов меню.

**Сид-данные:** 4 педагога (Петрова Анна — математика/ОГЭ, Ким Денис — информатика/Python, Соловьёва Ирина — математика ЕГЭ,
Орлов Максим — информатика ЕГЭ), 4 кабинета, ~12 учеников 6–11 классов с родителями (часть на абонементе, часть поурочно),
2 группы (ОГЭ-9А, Python-1), серии расписания на текущий и следующий месяц, 4 тарифа, шаблон ставки 700 ₽ + ступени 30/45 ч,
пользователи: owner@lidd.school, admin@lidd.school, kim@lidd.school (пароль из .env).

## Этап 2. Уроки (расписание)
- Вид «День» (колонки — педагоги или кабинеты), «Неделя», «Месяц», «Список»; фильтры; сводка дня.
- Создание урока и серии в выезжающей панели; проверка конфликтов педагога и кабинета.
- Панель урока: статус, посещаемость по ученикам, тема и ДЗ, перенос/отмена, блок «Финансы урока» (только OWNER).
- Отметка урока создаёт `Attendance`, `TeacherAccrual`, а для поурочников — `LedgerEntry` при неоплате.
- **Готово, когда:** урок можно создать, отметить, перенести, отменить; начисления педагогу пересчитываются.

## Этап 3. Клиенты и оплата
- Клиенты: таблица с поиском, фильтрами и массовыми действиями; карточка с вкладками.
- Платежи: приём оплаты, журнал, корректировки и возвраты с обязательным комментарием, баланс.
- Абонементы на месяц: генерация счетов 25 числа (cron), экран «Абонементы на месяц», предпросмотр и отправка сообщения.
- Поурочная оплата: ссылки за 48 ч, дедлайн за 24 ч, пометка «под угрозой».
- Telegram-бот для родителей (привязка по ссылке-приглашению), отправка расчётов и напоминаний.
- **Готово, когда:** полный цикл «расписание → счёт на месяц → сообщение родителю → оплата → баланс 0» работает.

## Этап 4. Педагоги и зарплаты
- Список педагогов со шкалой часов и надбавкой; карточка «Ставка и надбавки»; добавление педагога с приглашением.
- Шаблоны ставок, индивидуальные планы, история изменений.
- Финансы → Зарплаты: начислено на сегодня, прогноз по расписанию, закрытие месяца, премии/штрафы, выплаты.
- «Мой заработок» для педагога.

## Этап 5. Задачи, лиды, отчёты
- Задачи: канбан и список, автозадачи (cron, дедупликация по autoKey), счётчик просроченных в меню.
- Лиды: воронка, карточка лида с историей касаний, пробный урок, расчёт предложения, перевод в клиенты.
- Отчёты: выручка, зарплаты, расходы, прибыль, по педагогам, по программам, посещаемость, отток; экспорт в Excel/PDF.

## Этап 6. Мобильная версия и запуск
- Адаптив для педагога: «Уроки» и «Мой заработок» (390 px).
- Деплой на российский хостинг, резервные копии БД, мониторинг ошибок.
- Импорт текущих учеников и расписания из таблиц.
